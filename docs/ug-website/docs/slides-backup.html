01 The problem

Traditional RAG fails on codebases.

One wrong top-1 vector hit poisons the whole neighborhood. Most real questions span five or more nodes — there is no single seed.

FAILURE · 01

Errors compound

A wrong top-1 vector hit taints every downstream expansion. The seed is the answer's blast radius.

FAILURE · 02

No single seed exists

"How does auth work?" lives across handlers, middleware, configs, types — at least five nodes, none privileged.

FAILURE · 03

MMR ≠ relevance

MMR optimizes diversity, not answer quality. The rerank step is a heuristic, not a retrieval signal.

Phase 1 · the turbo indexer

A 1,000-file repo, in seconds.

  • Parallel crawler — rayon over ignore, respects .gitignore
  • Incremental indexing — blake3 hashes → only re-parse changed files
  • AST extraction — TypeScript · Python · Markdown (CommonMark)
  • Rust-first dispatch — crawl() → parse_ast() → structured nodes + edges, all in native code
native/src/indexer.rs
use rayon::prelude::*;
use ignore::WalkBuilder;

fn crawl(root: &Path) -> Vec<FileNode> {
    WalkBuilder::new(root)
        .build()
        .par_bridge()
        .filter_map(|entry| {
            let p = entry.ok()?.into_path();
            let hash = blake3::hash(&fs::read(&p).ok()?);
            parse_ast(&p, hash)   // tree-sitter
        })
        .collect()
}

★ Phase 4 · the headline

Many seeds. One walk. Token-budgeted answer.

We replaced the legacy vector top-1 → BFS → MMR rerank with Personalized PageRank seeded by RRF, HippoRAG-style. Legacy MMR remains behind strategy:"mmr" for diversity-first callers.

stage 1 RRF seed pool · vector + FTS

top-16 hits → weighted personalization vector (not fixed BFS roots)

stage 2 Personalized PageRank

random walk + restart α = 0.15 · edge-type weights · L1 tol = 1e-4

stage 3 Token-budgeted assembly

top-K by PPR · attach snippets · apply char budget

MCP-native search · traverse · find_symbols over stdio or HTTP — drop-in for any MCP agent
PPR · tuning knobs

The edge-weight ladder is the soul of the retrieval story.

parameterdefaulteffect
pprRestartProb (α)0.15Teleport prob. Higher → near seeds; lower → centrality dominates.
pprMaxIter100Power-iteration cap (L1 tol = 1e-4).
pprSeedPool16RRF hits feeding the personalization vector.
pprEdgeWeightsper-typeOverride edge-type weights (case-insensitive).

Scaling note: PPR loads the full edges table per query — single-digit ms via sparse iteration at ≤100K edges. Past ~1M edges, switch to subgraph restriction or precomputed PPR vectors.
