System Architecture

From source code to a queryable knowledge graph

UltraGraph's four-phase pipeline transforms codebases and documents into an interactive, retrievable, and AI-ready semantic graph — engineered in Rust for speed and exposed via Node.js for flexibility.

Input

Source codebase

Any directory — local repository, monorepo, or documentation tree.

Phase 1

Turbo Indexing

native · multi-threaded

Native Rust crawler maps codebases in milliseconds, using tree-sitter ASTs for symbol extraction.

File discovery — `.gitignore` aware
tree-sitter AST parsing
Symbol extraction — functions, classes, imports
Incremental — blake3 hashing
Languages
TypeScript JavaScript Python Java Markdown
Phase 2

Graph Synthesis

structural analysis

A rich symbol graph with relationships, hierarchy, and structural metrics computed in-process.

Nodes
Folder File Function Class Interface Concept Dependency
Edges
Contains Imports Calls Extends References
Algorithms
BFS / K-hop Cycle detection Centrality Shortest paths
Branch A

Visualize

Premium D3.js force-directed graph with interactive exploration in the browser.

D3.js force-directed layout
Interactive zoom, drag, filter, search
Live server health & DB enrichment
Phase 3

OverGraph Storage

Hybrid vector + FTS persistence with incremental ingestion and in-process embeddings.

OverGraph table — Vector + FTS
Local ONNX — fastembed-rs (default)
Remote — OpenAI-compatible /v1/embeddings
Auto-probed dim — persisted to ug-meta.json
Phase 4

GraphRAG Search

PPR · MMR · RRF

State-of-the-art retrieval combining semantic relevance with structural graph importance.

Vector-semantic search over embeddings
FTS-keyword full-text retrieval
RRF fusion reciprocal rank merging
MMR reranking diversity-aware
Personalized PageRank (default)
K-hop expansion on graph edges
Output

AI Agent via MCP Server

stdio

A stdio-based Model Context Protocol server exposes the knowledge base to any compatible AI agent.

# Tools exposed to the agent
context — ONE symbol, everything about it
search — GraphRAG retrieval (PPR-based; expand:false for seeds only)
traverse — K-hop walk from a symbol
find_usages — locate symbol references
find_symbols — lookup by name or wildcard
file_outline — symbols in a file, or a path glob
get_code — read source for a symbol or range
analyze — whole-repo statistics in one call
graph_schema — node & edge types, with counts

# `context` is the one an agent reaches for first: source,
# callers with call sites, covering tests, deps and docs —
# one budgeted call in place of five, each item labelled
# with the role that put it there.

# Every symbol/file argument takes an id, a name or a
# wildcard — so 'validate_*' is one call, not nine.
