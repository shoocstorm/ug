                        Graph Walk
                        
                    

                    

                        
Watch the graph walk. Pick a seed node, choose a
                            hop radius and direction, and the canvas isolates to the BFS frontier
                            one hop at a time — edges stream outward first, then each
                            frontier ignites in its own colour with a ripple from the seed. Everything off the
                            walk is hidden, so the expansion is all you see. Slow it down with the speed
                            control. This is the same N-hop walk behind the graph channel of
                            hybrid search.


                        
                        

                            
                            
                            

                        

                        

                        
Tip: select any node anywhere in the graph — it becomes the seed.

                        How this powers hybrid search
                        
                    

                    

                        

                            
The hybrid retrieval pipeline

                            

                                An AI agent's search call doesn't just keyword-match.
                                Semantic + keyword hits fuse into seeds, which are then
                                expanded through this exact graph walk (or Personalized
                                PageRank) so the model sees structurally-related code too. Run the walk above
                                and the graph stage below pulses in sync with each frontier.

                                        search
                                        MCP tool · the whole pipeline
                                    

                                    

                                        
The primary knowledge-base search an
                                            AI agent calls (Claude, Cursor, Windsurf…). Runs the entire
                                            pipeline above — RRF seeds → graph walk / PPR → ranked
                                            context — in one call. Trigger phrases include "how does X work"
                                            or "before I change X look up…".

                                        
// what the agent sends
search({
  query: "how does the embedder probe its dim",
  k: 8,
  direction: "both",
  edgeTypes: ["calls", "imports"]
})

                                    

                                

                                

                                    

                                        traverse
                                        MCP tool · the raw walk
                                    

                                    

                                        
A direct N-hop walk — the same BFS you're
                                            watching here — for drilling out from a node search
                                            returned. Output is grouped by hop with an edge-type tally. Reads
                                            the structural graph directly, so it works even without an embedding
                                            backend.

                                        
// the walk above, as an agent calls it
traverse({
  nodeId: "fn:native/src/storage/query.rs::search_kb",
  hops: 3,
  direction: "outbound"
})
